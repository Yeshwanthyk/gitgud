# Overlay project state and treat agent state as a Projection

Project-local Profile intent overlays the global Profile; local same-name intent wins and conflicts inside one Scope fail. Agent directories are derived Projections and gitgud changes only entries it owns unless forced. Every Generation publication auto-syncs; partial Projection returns a committed-but-degraded result with exit 3, while interruption always exits 130 and reports whether commit already happened. `gitgud sync` is the convergent retry.
